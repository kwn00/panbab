# 판밥

2판교의 오늘 점심 메뉴판을 모으는 모바일 우선 웹앱. Next.js App Router, React, TypeScript로 구현했습니다.

**방문 시 네이버 카페에서 조회하고, 서버 공용 캐시를 5분 동안 재사용합니다. Cron, 로그인, DB, 별도 환경변수는 필요하지 않습니다.**

## 실행 / 배포

Node.js 22 LTS 또는 24 LTS를 권장합니다.

```sh
npm install
npm run dev
```

http://localhost:3000 에서 확인합니다. 실제 공개 게시글을 사용하며, 데모 메뉴나 임의 식단을 표시하지 않습니다.

Vercel에서 이 저장소를 Next.js 프로젝트로 연결하면 됩니다. Cron을 등록하거나 `CRON_SECRET`을 설정할 필요가 없습니다. 원문 접근 가능 여부는 배포 환경 IP에 따라 달라질 수 있으므로 첫 배포 후 실제 메뉴와 함수 로그를 확인하세요.

## 수집과 캐시

```text
방문 / 메뉴 조회
  → 한국 날짜별 서버 캐시 확인
  → 캐시가 있으면 즉시 반환
  → 처음 조회하거나 캐시가 만료되면 네이버 공개 글 확인
  → 원본 이미지 주소와 텍스트를 반환하고 5분 캐시
```

- 출처: [2판교 라이프 · Today 밥집 메뉴](https://cafe.naver.com/f-e/cafes/30487307/menus/26?viewType=L).
- 서버 시간대와 무관하게 `Asia/Seoul`의 **당일 00:00 이상, 12:00 미만**에 작성된 공개 점심 글만 포함합니다. 현재 시각보다 미래인 글은 제외합니다.
- 10:30에 마감하지 않습니다. 11시 이후 새로 올라온 메뉴도 다음 캐시 갱신 때 반영합니다. 아침 일찍 방문해도 이미 게시된 메뉴는 바로 보입니다.
- 이전 날 작성된 주간 식단을 오늘의 새 글처럼 재사용하지 않습니다. 제목에 다른 식사 날짜가 있는 글, 공지·운영 안내·비공개 글도 제외합니다.
- Next.js `unstable_cache`의 **300초 재검증**을 사용합니다. Vercel에서는 내장 Data Cache로 여러 함수 인스턴스가 캐시를 재사용합니다. 로컬에서도 같은 Next.js 캐시 경로를 사용하며 별도의 JSON DB나 `/tmp` 저장소는 없습니다.
- 캐시 키에 한국 날짜가 포함되어 자정 이후 전날 메뉴가 오늘 메뉴로 섞이지 않습니다.
- 캐시 만료 직후에는 이전 응답을 먼저 반환하면서 백그라운드 갱신하는 stale-while-revalidate 방식입니다. 화면에 실제 확인 시각과 오래된 캐시 안내를 표시하며, 갱신 중에는 짧게 재조회합니다.
- 페이지가 보이는 동안 자동으로 캐시를 재조회하고, 숨겨진 탭에서는 주기 요청을 하지 않습니다. 접속자가 없으면 수집 작업도 실행되지 않습니다.
- 조회는 필요한 날짜까지 최대 10페이지, 본문은 최대 3개 동시 요청으로 제한합니다. 타임아웃, 응답 스키마 검증, 동일 프로세스 내 중복 요청 병합을 적용합니다. 로그인 쿠키나 계정을 사용하지 않습니다.
- 원문 오류는 빈 메뉴로 위장하지 않습니다. 최초 조회 실패는 오류 화면, 재조회 실패는 기존 메뉴와 경고를 표시합니다. 비공개로 변경된 글 등 제외 항목도 경고로 안내합니다.

최근 14일의 날짜를 선택할 수 있지만 **영구 보관 기능은 아닙니다.** 캐시가 없어지거나 원문이 삭제되면 이전 상태를 복원하지 못할 수 있습니다. 과거 기록이 필요해지면 `src/lib/menu-service.ts`의 수집 결과를 Supabase에 날짜/게시글 ID 기준으로 저장하는 계층을 추가하면 됩니다. 지금은 Supabase 연결이 없습니다.

## 원본 메뉴판

모든 이미지를 원문 순서대로 유지하며 **OCR, AI 요약, 메뉴판 재작성은 하지 않습니다.** 텍스트 글은 텍스트 메뉴로 표시합니다.

이미지 파일을 DB에 복제하지 않고 네이버 원본 주소를 사용합니다. 목록과 확대 보기에서 원본 이미지를 표시하며 여러 장은 좌우 버튼과 키보드로 넘길 수 있습니다. 파일명에 게시 날짜가 명시된 이미지가 있으면 대표 이미지로 먼저 보여주되 나머지 이미지도 모두 유지합니다. 이 규칙은 OCR을 사용하지 않으며 이미지가 실제 메뉴인지 자동 판정하는 기능은 아닙니다.

각 글에 원문 링크와 출처를 제공합니다. 식당의 가격·거리·영업시간은 추측하지 않습니다. 같은 이름의 지점은 구분합니다. 검색은 식당·건물 이름을 대상으로 하며 이미지 속 음식 이름을 검색하지 않습니다.

공개 열람과 외부 서비스 재사용 허가는 별개입니다. **공개 배포 전 네이버 정책 및 운영진·작성자의 이미지 재사용 허용 범위를 확인하세요.** 이 앱은 네이버 또는 카페의 공식 서비스가 아닙니다.

## 화면

- 모바일 1열 / 태블릿 2열 / 데스크톱 3열 반응형 카드.
- 원본 크기 확대, 다중 이미지 탐색, 카페 원문 이동.
- 날짜 선택, 식당 종류 필터, 식당·건물 검색.
- 브라우저에 식당 북마크 저장. 계정 간 동기화는 하지 않음.
- 로딩 / 빈 메뉴 / 검색 결과 없음 / 네트워크 오류 / 원본 이미지 오류 / 오래된 캐시 상태.
- 키보드 탐색, Escape 닫기, 모션 감소 설정 지원.

## 개발 확인

```sh
npm test
npm run lint
npm run typecheck
npm run build
npm run test:e2e
```

단위 테스트는 한국 날짜 경계, 정오 마감, 미래 게시글 제외, 5분 캐시 경계, 이미지·텍스트 보존, 공개 범위, 페이지네이션, 오류 전파를 확인합니다. 브라우저 테스트는 테스트 전용 응답·이미지를 명시적으로 모킹하여 320~1440px 레이아웃, 검색, 날짜, 북마크, 이미지 확대, 키보드, 오류 상태를 확인합니다. 첫 브라우저 실행 시 Chromium이 없다면 `npx playwright install chromium`으로 설치하세요.

네이버 화면에서 관찰한 공개 데이터 요청을 사용하며 공식 장기 지원 API 계약은 아닙니다. 구조 변경·접근 제한 시 수집기가 실패할 수 있습니다. 캐시는 DB가 아니며 프로덕션과 미리보기 환경은 분리됩니다. 자세한 동작은 [Vercel Data Cache 문서](https://vercel.com/docs/caching/runtime-cache/data-cache)를 참고하세요.
